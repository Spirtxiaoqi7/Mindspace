# 典藏卡册美术资源规范

> 0.7.0 扩展：清单现为向后兼容的 `2.0.0`。旧资产可继承 `defaults`，新增共同篇章资产必须
> 显式填写 `pack_id`、`theme`、`usage`、`dimensions`、`bytes`、
> `min_app_version`、`license`、`sha256` 与 `fallback`。12 项代表预览位于
> `archive/previews/index.json`，已于 2026-07-30 通过视觉审核并完成正式资源扩产。

默认人物占位资源统一采用原创二次元风格。禁止在抽卡工坊、空状态或公共示例中混入真人写实头像，以免与产品既有角色卡视觉跳脱；用户上传头像只属于本地角色数据，不进入公共资源库。

资源入口为 `frontend/public/archive/manifest.json`。构建后通过
`/assets/archive/manifest.json` 访问。每个条目记录稳定 ID、类型、公开
路径、授权、SHA-256 与降级资源。用户头像和私人角色卡禁止写入该目录。

0.7.0 正式内置库包含 171 项，其中 164 项为共同篇章规划资源，另保留 7 项 0.6
兼容资源：

- 72 个紧裁剪 SVG 图标。
- 24 个二次元手账 SVG 贴纸。
- 16 套卡框、日记边框与弹窗装饰。
- 12 套 WebP 纸张、夜色与季节纹理。
- 12 张空状态、生成中与失败状态插画。
- 20 张活动场景缩略图。
- 8 套 WebP 日记封面。
- 4 张兼容占位头像和 3 套兼容交互动效。

`scripts/build_art_library.py` 负责确定性生成、场景安全裁剪、WebP 压缩、逐文件 SHA-256、
类别数量和 15MB 上限校验。在线生成只用于首轮原创场景概念；正式构建与重新打包不依赖
图像服务。

边框和图标保持矢量；纹理和头像使用 WebP。界面不得依赖单张资源才能使用：图片失败时使用
Manifest 指定的默认头像、文字或纯色边框。所有页面必须在 Windows 125%/150% 缩放、
1366×768 与 1920×1080 下无水平溢出。

新增公共资源必须重新计算 Manifest SHA-256，写明来源和授权；不允许把用户上传图片、
私人角色设定或本地聊天截图作为样例提交。

Manifest v2 新增字段：

- `pack_id`：`core` 或独立扩展包 ID。
- `theme`：视觉主题，例如 `anime-scrapbook`。
- `usage`：允许使用的产品场景，避免资源被误用为人物头像或私有内容。
- `dimensions` 与 `bytes`：安装前预算和布局占位。
- `min_app_version`：防止旧版本解释不了新资源类型。
- `packs`：只列可选下载包；下载 URL、字节数与 SHA-256 缺一不可。
