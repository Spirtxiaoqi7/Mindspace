# 典藏卡册美术资源规范

默认人物占位资源统一采用原创二次元风格。禁止在抽卡工坊、空状态或公共示例中混入真人写实头像，以免与产品既有角色卡视觉跳脱；用户上传头像只属于本地角色数据，不进入公共资源库。

资源入口为 `frontend/public/archive/manifest.json`。构建后通过
`/assets/archive/manifest.json` 访问。每个条目记录稳定 ID、类型、公开
路径、授权、SHA-256 与降级资源。用户头像和私人角色卡禁止写入该目录。

首版包含：

- 两套模式入口 SVG 卡框。
- 四种角色状态符号。
- 三套 WebP 响应式底纹。
- 十二个性格分类 SVG 符号。
- 八个关系印章 SVG 符号。
- 六个角色库操作 SVG 符号。
- 四张原创二次元 WebP 占位头像。
- 三套卡片交互动效及 `prefers-reduced-motion` 降级。

边框和图标保持矢量；纹理和头像使用 WebP。界面不得依赖单张资源才能使用：图片失败时使用
Manifest 指定的默认头像、文字或纯色边框。所有页面必须在 Windows 125%/150% 缩放、
1366×768 与 1920×1080 下无水平溢出。

新增公共资源必须重新计算 Manifest SHA-256，写明来源和授权；不允许把用户上传图片、
私人角色设定或本地聊天截图作为样例提交。
