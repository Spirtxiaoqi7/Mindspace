# 0.8.3 原生工具能力

> 状态：current。

模型只有在需要外部信息时输出一条短工具指令。宿主授权并执行，结果作为不可执行数据回注。普通聊天不经过旧 planner/research/repair 链，也不会因为关键词命中而伪造已调用工具。

当前工具分级：`web` 与 `memory` 为 L3，命中合法单指令后执行；`task` 为 L2，先独立审查再写入；本地命令只保留 L1 设计位，不注册执行器。

每轮最多一个工具 attempt。第二次模型生成不再开放工具。工具失败会持久化失败状态并让模型基于失败事实继续回复，不得声称已经联网核实、已经查询记忆或已经完成任务。

前端工具卡只读取当前回合持久化 attempt；`null`、空数组或无 request 的回合不显示占位卡。刷新后按 run/turn ID 恢复。
