启动边界

关闭主界面只截断当前输出，不销毁已经预热的语音服务。彻底退出 Mindspace 时，启动器才释放 ASR、TTS 与显存。

关闭通话

停止当前播放和订阅；ASR Worker 保持常驻，不重建麦克风。

停止全部

按 TTS → ASR → Core 顺序停止，并明确显示未退出的进程。

诊断与更新

先给用户可理解的结果，再提供原始日志。任何失败都应该说明影响范围和下一步，而不是只显示错误码。

快速自检

检查 Core、麦克风首帧、当前 TTS 和播放设备，不生成正式对话。

复制诊断

复制脱敏后的端口、端点、首帧耗时、队列深度和最近错误。

组件修复

只补齐缺失或校验失败的文件，不重装已经通过的环境。
